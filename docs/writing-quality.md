# 日本語文書の確認

```sh
agent writing-check --source original.md --candidate draft.md --style polite --must-keep 青葉会議 --must-keep 参加費0円
```

ローカルの UTF-8 ファイルを読み、推論・送信・編集せずに結果を JSON で表示します。原文と候補はそれぞれ1 MB・10,000行までです。出力には対象テキストの SHA-256、該当行、根拠となる表記、検査の限界を含みます。

- **error**: 利用者が `--must-keep` で明示した完全一致文字列が出力にありません。この場合だけ終了コード1です。
- **review**: 日時・単位付き数値・URLの元の表記が見つからない、指定用語との表記ゆれ、敬体・常体の文末、助詞重複の可能性、長文です。誤検出があるため不合格と断定せず、原文と照合してください。
- **truncated**: 指摘数または検査量の上限に達しました。範囲を分けて再検査してください。検査量上限は1,000種類の事実候補、表示上限は200指摘です。

用語は `--terminology terms.yaml` で指定できます。

```yaml
- preferred: ユーザー
  alternatives: [ユーザ]
```

これは表記上の補助検査であり、完全な校正や意味の正しさを保証しません。固有名詞、読者への適合、指示、否定、条件、例外、根拠のない事実の追加は、人または独立レビューで確認する必要があります。同じ数値を別の対象へ付け替えても検出できません。等価な日時表記への変更、引用、コードは誤検出になり得ます。終了コード0は文書全体の品質合格を意味しません。
