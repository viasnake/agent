# 調査と文書の確認

## Web の明示的な許可

通常の入力で調査を依頼します。種類の自動判定が合わない場合は `/kind` で research を選択します。読み取り専用の調査は回答で終わり、文書作成を許可した依頼は既存の検査を通して Markdown 成果物を保存します。

Web 検索・取得は research のときだけ利用できます。検索には設定ファイルの `web.search` が必要です。既定の公開検索先や未設定時の代替サービスはありません。以下は形式の例で、実際に動作するサービスの指定ではありません。

```yaml
web:
  allowedHosts: [search.example.com, sources.example.com]
  allowedData: [public]
  search:
    endpoint: https://search.example.com/search
    queryParam: q
```

検索先は HTTPS、明示許可ホスト、443番ポートのみです。資格情報・クエリ・フラグメントを endpoint に含められません。GET のクエリ引数へ検索語を渡します。JSON なら `{ "results": [{ "title": "題名", "url": "https://sources.example.com/page", "snippet": "発見用の短文" }] }`、HTML なら安全なリンクを検索結果として扱います。検索結果の URL が許可されていない場合は取得できません。リダイレクト先にも同じ安全確認を適用します。秘密情報を検索語に含めないでください。

`localOnly` と `restricted` では Web を呼びません。それ以外でも、会話・添付の送信区分が `web.allowedData` に含まれなければ呼びません。取得は非公開ネットワーク宛先を拒否し、サイズ・時間・リダイレクト回数を制限します。ページの JavaScript は実行せず、リンクを自動追跡しません。

## 検索と根拠は別の記録

- `search_web`: 検索語、検索先、日時、応答ハッシュと発見用の結果を保存します。スニペットは本文の根拠として引用できません。
- `fetch_source`: 許可されたページの応答バイト列を非公開の `source-raw` として保存し、別に文字コードを検査した抽出本文 `source` を作成します。`read_source` と引用は抽出本文だけを対象とします。
- 抽出情報には URL、最終 URL、取得日時、Content-Type、抽出バージョン、raw ID/hash、リンク、提供元が申告した公開・更新日時を保持します。取得日時は公開日時ではなく、申告日時の正しさも検証済みとは限りません。
- 根拠は `[source:UUID:L1-L5]` のように保存済み ID と行範囲で参照します。引用の構文・範囲検査が通っても、主張を意味的に裏付けるとは限りません。

`/research` で調査メモ、検索履歴、検索先の設定を確認できます。画面の閲覧は通信や再取得を行いません。調査メモは要約・調べた範囲・未解決事項・根拠 ID 付きの判断を保持するモデル作成の未検証記録です。ユーザーの固定メモ・制約・権限とは別物です。

## 今後の送信から資料を除外

`/sources` → 資料を選択 → 除外を選択します。`/sources exclude <資料ID>` でも確認画面を開けます。実行内容の画面と最後の確認で取り消せます。

同じ raw 原資料の別ページ・別の選択範囲、関連する PDF 画像、Web の raw/抽出本文をまとめて対象にします。確認後に対象やポリシーが変わった場合は古い確認を拒否します。作業中は除外できません。除外前の作業・モデルセッションを再開せず、新しい依頼として続けてください。変更された待機入力は再確認が必要です。

**これは削除・完全な匿名化ではありません。** 元ファイルと履歴は不変で、過去の回答・引用・要約・言い換え・送信済みデータを取り消しません。除外された元資料も利用者向けのローカル履歴には残ります。モデルの新しい資料取得・継承・作業コピーには除外制御を適用します。除外前の原文が含まれ得るコンテキストアーカイブは、その会話から取得できなくなります。

## 文書の版と来歴

`/versions` はこの会話の文書を新しい順で30件ずつ表示します。`/versions article.md` で名前を絞れます。選択した版の Markdown 表示、来歴、同名の別の版との差分を確認できます。差分は比較前・比較後の ID を表示し、文書や元の workspace を変更しません。UTF-8テキスト以外やサイズ・編集量・時間の上限を超える比較は明示的に失敗します。

来歴は次を区別します。

- 生成時に利用可能だった資料（実際に読んだ・引用した証明ではありません）
- 文書に記載された引用範囲（引用の正しさの証明ではありません）
- 生成した作業と親作業
- 実際に保存された検査 ID/hash と結果（意味・事実の正しさの保証ではありません）

古い形式の成果物は来歴不明と表示します。失敗・修正前の版も残します。文書の外部編集は `/editor artifact` で改訂案を下書きへ戻し、元の版を上書きしません。PDF/DOCX 出力や実モデルの品質比較はこの機能の受入範囲ではありません。
